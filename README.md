# Laquna

A deterministic, reversible byte transform for at-rest content opacity.

**Laquna is not encryption.** It provides friction against opportunistic,
at-scale content extraction. It does not provide confidentiality,
authentication, or resistance to a motivated adversary.

- [`laquna/`](laquna/): the Rust crate. Start with its [README](laquna/README.md).
- [`docs/`](docs/): design, format, and conformance documentation.
